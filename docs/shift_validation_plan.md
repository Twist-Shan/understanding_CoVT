# 冻结状态的扩展验证计划

目标是检验前次固定状态与原生状态读出接近的现象能否跨几何条件成立。本轮是探索性扩展，不据此建立总体等价性结论。

- 新 seed=1901，50 个场景族，每族 base、depth_swap、nuisance、label_swap，共 200 张图。
- 五类变化各十个族：物体尺寸变化、椭球、盒体、部分遮挡、相机参数变化。
- 每个族在模型运行前检查两个标记的可见邻域、点与邻域深度顺序，以及深度交换和标签交换是否翻转真值；失败则按固定随机流重采样，记录数量。
- 部分遮挡条件要求独立物体投影实际相交，同时保留两个被查询邻域可见。
- 全部是评估场景。固定状态来自上一轮八个合格校准样本；沿用其深度方向、尺度和 0.05 弃权阈值，不在新数据重标定。
- 200 张图全部测试专家原生深度、固定校准均值状态和固定校准示例状态，专家与解码器在 GPU 上执行，均为 FP32。
- 前十个族（各类两族）在生成器中预先选为原生对照，共 40 张图。执行 FP32 生成、cached/uncached 对照、固定序列 identity、专家重复与解码 identity 检查；原生对照结论限于此子集。
- 子集上比较原生、固定均值、固定示例、五次跨族状态和五次无固定位置的 token 排列。只用全部检查合格的状态作 donor；明确保留失败分母。
- 问题固定为 closer to the camera，字体 24 px。相对于旧批次，问法、标注和几何都改变，因此不把跨批答案准确率变化解释为单因素效应。
- 保存每张图像和完整几何参数、固定读出地图、逐样本生成记录、40 张图像的专家特征和原生状态、校验索引与统计结果。

统计按场景族聚合；重复 seed 先在族内平均。若 donor 被重复使用，普通 recipient-family bootstrap 不充分表示 donor 相关性，因此随机状态条件的区间仅作探索性描述，不作为确认性检验。原生/固定对照使用同一目标图像的配对结果。

运行入口：`scripts/shift_validation.py expert`，随后 `scripts/shift_validation.py native`。全部实验在 Colab 上执行；本机仅编辑、归档和读取统计结果。
