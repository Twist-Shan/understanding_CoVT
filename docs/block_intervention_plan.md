# 连续层与全层干预计划

2026-09-18。实验只在 Colab A100 上运行，沿用 FP32、eager、关闭 TF32。入口 `scripts/block_intervention.py`。

固定上一轮 20 张可配对图像、6 个场景族，大小一致/冲突各 10 张。依次执行 0–8、9–17、18–27、0–27 层输入的联合替换，前四阶段均只覆盖四个自然深度 pad。层号从零开始。

每个阶段包含原样写回、同族相反深度供体、跨族同深度供体。后者匹配真值 A/B、depth_order、size_order、大小线索类别，并按 ID 确定性循环选择供体。所有供体必须匹配输入长度、深度位置和从提示结束到最后深度 pad 的 token 序列。跨族控制仍混有场景族差异，不等价于只改变一个语义因素的理想控制。

每一层写入对应供体在该层的自然状态，后续每步均完整重算并重新施加替换，不使用旧 KV。报告自由生成、严格格式有效性、有效答案翻转、无效输出、A/B 固定上下文概率、逐层状态距离，以及相反/同深度供体的配对差。

预先指定扩展规则：如果四个深度位置的全 28 层相反深度替换没有有效答案翻转，再将位置扩大为从提示结束到最后深度 pad 的全部自然思考前缀位置，仍在全部 28 层替换并重复两个供体条件。这不含供体答案 token，不覆盖图像 token；其效应不能直接归因于深度 pad。

原样写回要求固定上下文 logits 逐位一致、自由生成 token 与原始基线一致。不同前缀长度状态检查沿用 `atol=1e-3, rtol=1e-5`，完整保存误差；这是工程检查，不是效应等价边界。严格答案要求一个完整答案标签且文本不存在冲突的 A/B；同时保留原解析器结果与原文，避免再次将格式损坏当作干净语义翻转。

只有 6 个独立场景族。族 bootstrap、多个阶段及条件扩展均为探索性分析；零翻转不证明总体效应为零。
