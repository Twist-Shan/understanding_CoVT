# FP32 E0 与状态对照结果

完整 FP32 语言模型在本次 40 张图像上通过全部 E0 检查。固定状态或跨图像替换状态后，32 张 pilot 图像的深度关系仍全部正确；打乱四个状态位置明显降低正确率，置零则全部弃权。结果支持进一步检验“稳定的位置结构与图像专家特征足以支持当前深度读出”的假设，不能据此断言语言答案没有使用深度状态。

## 设置与一致性

所有实验在 Colab A100-SXM4-40GB 上执行，本机仅编辑与归档。固定模型、源码和专家版本沿用首轮，语言模型改为 FP32、eager attention，专家使用 Colab CPU。新 seed=18，10 个场景族，每族四个变体；前两个族用于校准，后八个族用于评估。模型未训练，E0 阈值未放宽。软件检查为 24 passed（3.82 秒）。

四图定向精度诊断见 [诊断记录](cache_precision_diagnostic.md)。完整 FP32 同时改变参数表示和计算精度；本次消除了观测到的 token 差异，但具体层或算子的原因未定位，不保证任意输入的缓存一致性。

| 指标 | 结果 |
|---|---:|
| 全部 E0 检查 | 40/40 |
| cached/uncached token 一致 | 40/40 |
| 合格校准图像 | 8/8 |

语言答案准确率为 25%，按场景族 bootstrap 的 95% 区间为 [9.375%, 40.625%]。24 张图像出现“解码关系正确、语言答案错误”。深度结果的区间退化为 [1,1]，不代表总体性能已确定；场景类型简单、独立场景族仍少。

## 末端状态对照

所有条件保留目标图像的专家特征，使用同一 E0 校准方向 −1、尺度 151.85319519 和弃权阈值 0.05。固定均值和固定示例只使用校准族，跨图像 donor 排除同一场景族。token 乱序使用无固定位置的排列；随机条件执行五个 seed，先在场景族内平均，不把重复视为新的独立样本。无对照被排除。

下表为原生 FP16 解码器在 GPU 上的结果。分数变化是相对于同精度原生状态的归一化关系分数绝对变化；深度图 RMSE 使用原始输出单位，不是米。

| 原生状态 | 100% | 0% | 0 | 0 |
| 固定校准均值 | 100% | 0% | 0.000523 | 0.1465 |
| 固定校准示例 | 100% | 0% | 0.000608 | 0.1649 |
| 跨图像状态 | 100% | 0% | 0.000726 | 0.1954 |

随机条件各有 32×5=160 次评估，独立场景族仍为 8。乱序正确率为 93/160，弃权为 2/160；其按族 bootstrap 的正确率区间为 [50.625%, 68.125%]。固定/跨图像条件保留了所有原生关系标签，但深度图并非逐像素相同。

将解码器改为 FP32 后，各条件正确率和弃权率保持相同。固定均值、固定示例、跨图像、乱序的平均绝对分数变化分别为 0.000493、0.000627、0.000711、0.841308，主要现象不依赖解码器 FP16 舍入。这里复用相同 E0 状态和专家缓存，并未重新生成状态。

零 hidden 仍会经过 MLP 偏置，不能在一般情况下等同于零投影 token；此处两者的汇总指标相同。两个零条件均是弃权，不能称为 32 个方向判断错误。

## 解释边界与后续选择

扩大的 E1 同时完成：8 个 pilot 场景族、16 个配对，无排除。depth-swap 的平均绝对状态效应为 0.000311，平均绝对专家效应为 1.802808；换状态时 0/8 关系符号翻转，换专家特征时 8/8 翻转。nuisance 条件对应效应为 0.000502 与 0.049131，两类替换均未翻转关系。E1 使用原生解码器在 GPU 上执行；其小效应的精度敏感性不能直接由不同干预的状态对照结果代替验证。

当前证据区分了两个问题：状态位置乱序会损害深度读出，但保持位置结构、替换为固定或另一图像的状态，影响很小。一个待验证的解释是四个位置提供稳定的读出结构，具体空间关系主要来自专家特征；目前尚未证明参数或状态可正式等价替换。

本实验没有在共享上游位置干预后重新生成答案。25% 的语言答案准确率也可能涉及合成场景、A/B 标记识别、问题理解等因素，不能单独解释成“模型忽略自己的 thought”。继续方向应优先扩大几何与标记对照、检验固定状态的跨分布表现，并定位真正影响答案的状态位置；暂不据此启动修复训练。
