# 七层深度状态干预扫描

日期：2026-09-18。执行位置：Colab A100，FP32 eager；不在本地运行实验。

复用 balanced-intervention-20260918-090000 中同场景、同表观大小、相反深度的 20 张可配对图像，共 6 个场景族；一致与冲突条件各 10 张。该子集经过深度 pad 可用性筛选，不能代表全部 32 张图像。

扫描从零计数的层 0、4、8、14、20、24、27，在各层输入处替换四个自然生成的深度 pad 的残差状态。每个目标包含原样写回、相反深度供体替换、置零三种条件。供体来自同场景族，保持表观大小顺序。置零属于分布外干预。

每种条件从最后一个深度 pad 后重新生成，重算完整前缀，不使用原答案后缀或旧 KV 缓存。最多生成 128 个 token，单独记录无效答案与未完成输出。另在原始答案 A/B token 前的固定上下文中，记录 A/B logit 差、全词表概率及条件概率 P(A | A 或 B)。固定上下文指标是诊断量，不等同于自由生成的总因果效应。

验证包括未干预输出复现、逐层原样写回、深度位置的前缀一致性，以及答案预测位置最终归一化状态的相反答案供体替换。最后一项仅检查读出测量流程能否检测答案改变，不是深度路径的正控制。

执行前验证修订：首次运行因不同前缀长度的状态不逐位相同而停止；增加数值记录后，第二次在第 17 个样本处超过 `atol=1e-4, rtol=1e-5`。此时尚未执行干预扫描。已观察最大误差约 4e-4。最终版本将跨长度状态诊断容差设为 `atol=1e-3, rtol=1e-5` 并保存全部误差；固定答案上下文使用在该上下文采集的状态，要求原样写回全词表 logits **逐位一致**。自由生成仍要求原样写回所有生成 token 与基线完全相同。该容差属于工程诊断，不能作为因果效应等价边界。

结果按层与干预报告。场景族 bootstrap 仅作探索性不确定性描述；样本量小，零翻转的退化区间不能证明总体效应为零。保存逐样本生成文本、token、概率、验证结果、脚本和归档校验值。
