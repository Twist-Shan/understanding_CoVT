# 大小平衡与中间状态干预

2026-09-18，探索性 pilot，seed=1902。所有渲染、推理和统计在 Colab 运行。

## 预定对照

8 个独立场景族，每族交叉远近顺序与投影大小顺序，共 32 张图；大小线索一致和冲突各 16 张，A/B 真值各 16 张。深度交换时保持角半径及横向位置比值，物体实际半径和接地位置随之变化，因此不是只改变物理深度的隔离干预。标记邻域必须完全位于物体内部，点深度差至少 0.4。沿用此前固定校准和固定状态。

## 干预

仅使用自然生成四个 depth pad、cached/uncached 一致、生成完整及 identity 合格的样本；保留所有失败分母。选择中间 Transformer block 的输入 residual，而不是最终归一化层。先截断在最后一个 depth pad 后；每一步完整重算，不复用旧 KV，也不保留原答案 token。替换四个位置后捕获其下游最终隐藏状态，同时重生成语言答案。

条件为无干预、原样放回、同族相同大小排列但相反远近的 donor、同标签同 cue 的跨族 donor、循环打乱四个 token。同标签跨族 donor 仍可能改变其他属性，不能当成纯语义控制。所有实验只固定一个中间层，不能将阴性结果推广到所有层。

先要求原样放回的后续 token 与无干预及原始完整生成完全一致，且最终状态和首步 logits 逐值一致；否则不对该目标报告因果结果。保存生成文本、token、donor、干预位置、状态变化量、深度 margin、正确率与无效答案。观察条件间变化不能自动解释为深度概念的纯因果效应。

统计区分全部尝试、自然深度状态合格、干预 identity 合格、各条件实际 donor 可用样本；按族统计。重复 donor 引入的依赖意味着区间仅作探索性描述。最终需在相同受试目标上比较相反深度与同标签 donor，避免不同缺失分母造成误解。

入口：`scripts/balanced_intervention.py`。独立运行目录，不覆盖此前实验。
