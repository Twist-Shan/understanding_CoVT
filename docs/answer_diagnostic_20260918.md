# 答案错误诊断：问法、标签识别与基座对照

两种模型都能完成本批图像的左右标签识别和图像中大小比较。更直白的近距离问法提高了观察到的准确率，但两种模型的标签交换一致性均不足；目前不能将首轮低准确率单独归因于字母尺寸，也不能归因为 CoVT 的答案读出机制。

## 设置

Colab A100-SXM4-40GB；FP32、eager attention、greedy generation，最多 192 个新 token。CoVT 版本沿用前次固定 checkpoint；基座为 `Qwen/Qwen2.5-VL-7B-Instruct`，固定 revision `cc594898137f460bfe9f0759e9844b3ce807cfb5`。使用各 checkpoint 的原生 processor/chat template，输入图像一致。该比较没有随机化训练条件，不能据此识别特定训练成分的作用。

固定选用上一轮八个 pilot 场景族的 base 和 label_swap，共 16 张图像，不按模型是否正确筛选。每个模型八种条件，共 128 次生成；两模型合计 256 次。未在这些结果上选择新的提示词。字母放大条件从原无标注图重新绘制同位置标记，字体大小为 24 px；其余条件保留原始图像。

所有输出均可按预先规定的选项解析，无截断。每种模型在第一个 base 样本的八种条件上额外检查 cached/uncached，均为 8/8 token 一致。此检查不覆盖所有 128 次生成。诊断使用不同输出集合时单独解析 A/B 或 left/right，不从推理文字中搜索答案字母。

## 准确率

每个表格单元的分母都是 16 张图像，独立场景族为 8。

| 条件 | CoVT | Qwen 基座 |
|---|---:|---:|
| 原技术问法：camera-axis depth / image plane | 6/16 | 8/16 |
| 直白问法：closer to the camera | 11/16 | 11/16 |
| 直白问法：farther from the camera | 8/16 | 5/16 |
| 哪个标签在图像左侧 | 16/16 | 16/16 |
| 哪个球在图像中占据更大面积 | 16/16 | 16/16 |
| 哪个球更近，回答 left/right | 9/16 | 7/16 |
| 放大字母后问哪个点更近 | 11/16 | 10/16 |
| 放大字母后识别左侧标签 | 16/16 | 16/16 |

CoVT 的原问法到直白近距离问法有 6 个样本由错变对、1 个由对变错；基座分别为 4 和 1。此处是配对的探索性结果，八个场景族不足以支持稳定总体差异。CoVT 的近距离准确率按族 bootstrap 区间为 [56.25%, 87.5%]，基座为 [50%, 87.5%]；两者区间重叠。

原问法的 6/16 与上一轮所有四种变体的 8/32 使用不同样本范围，不能解释为复现性能提高。

## 一致性检查

| 检查 | CoVT | Qwen 基座 |
|---|---:|---:|
| 同一图像问近与问远，答案互为相反标签 | 9/16 | 10/16 |
| 交换 A/B 标注后，近距离答案相应翻转 | 3/8 个族 | 3/8 个族 |
| 交换字母标注后，left/right 近距离答案不变 | 7/8 个族 | 5/8 个族 |

近/远一致性仅衡量是否互补，不保证两题都正确。标签交换保持物体与几何不变，只改变字母标注。11/16 的近距离正确率同时存在较差的配对一致性，因此不能视为已经稳定掌握本任务。

## 当前结论

本批图像上的简单标签识别和投影面积比较可完成；深度问题的问法与标签交换会改变行为表现。低深度答案准确率的具体原因未查明。现有数据没有显示 CoVT 在直白近距离条件下优于对应基座，也没有建立 thought 与答案的因果联系。

后续扩展预先采用直白问法和 24 px 字母，并同时改变几何场景；与首轮的跨批性能差异不能单独归因于几何或字体。扩展的主要对照是在同一批输入上比较原生状态与固定状态，保持前次校准不变。共享上游干预与修复训练尚未执行。
