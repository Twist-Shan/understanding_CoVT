后续更新：精度诊断与 FP32 的 40 图验证已完成，见 [后续实验报告](colab_20260918_followup.md)。下文保留首轮 BF16 结果及其当时的限制。

原生深度分支已使用官方 checkpoint 权重运行并生成深度图。12 张图像均生成四个 depth-pad token；10 张通过全部 E0 检查。另 2 张的 cached/uncached 生成仅在最终答案 token 上不同，原因未查明。E1 有效样本仅包含一个场景族，结论限于本次局部解码实验。

## 实验目的与设置

E0 检查公开权重能否支持原生深度读出，以及生成、固定序列重放、专家重算和解码器 identity 的一致性。E1 测量固定专家特征时替换深度状态、固定状态时替换专家特征，对读出关系分数的影响。

- 执行位置：Google Colab，NVIDIA A100-SXM4-40GB。实验未在本机运行。
- [Colab 笔记本](https://colab.research.google.com/drive/1l8LMcYt2K8H0uzEeBdFZ8mpq47DuaXqr?authuser=1)。
- 环境：Python 3.11.16、torch 2.5.1、transformers 4.50.1、torchvision 0.20.1。完整依赖见 `colab_20260918_metadata.json`。
- 模型与源码均使用预先审计的固定版本；专家权重版本为 `cbbb86a30ce19b5684b7a05155dc7e6cbc7685b9`。
- E0：BF16 语言模型、eager attention，原生解码器保留 checkpoint 的 FP16 参数，专家以 FP32 在 GPU 上执行，greedy generation，最多 192 个新 token；没有训练或量化。
- 数据：seed=0，三个解析球体场景族，每族 base、depth_swap、nuisance、label_swap 四个变体，共 12 张图。scene_00000 为校准族，另两个为 pilot 族。
- 软件测试在 Colab 上执行：22 passed，3.99 秒。原始恢复算子对照误差为 0；此项仅验证合成张量上的重建算子。

## 指标定义

在 A/B 标记周围固定环带上取深度中位数，计算原始差值。仅由合格校准样本固定方向和尺度，弃权阈值为尺度的 0.05。此次解码方向为 -1、尺度为 137.54537963867188，校准样本数为 3。

说明性示例：在本次校准方向下，原始差值为负对应 A 更近。该例解释指标方向，不增加实验样本。

E1 的 r_uv 表示使用状态 H_u、专家特征 F_v 得到的归一化关系分数。状态效应为 r_10-r_00，专家效应为 r_01-r_00。深度交换的定向效应根据 donor 标签统一符号。

软件输出的语言答案准确率按场景族等权聚合，为 0.2916667；按图像聚合为 2/7。两个 pilot 族的合格样本数分别为 3 和 4，因此两个统计口径略有差异。如此少的场景族不足以估计稳定的总体准确率；深度准确率的退化 bootstrap 区间 [1,1] 不应解释为总体确定性。

不合格样本为 `scene_00000_nuisance` 与 `scene_00001_base`。两种缓存设置的输出均为 24 个 token，差异仅位于 continuation 的第 20 个位置（从 0 起算）：cached 为 token 33（B），uncached 为 token 32（A）。四个 depth-pad 位于完整序列的 203–206，用户前缀长度为 192。原始 `<answer>A/B</answer>` 与解析答案一致；此次低答案正确率未发现由答案解析造成的误判。

缓存差异原因未查明。需在相同前缀上比较 A/B 的 logits 和缓存模式，并用更高精度验证；当前不得直接归因为浮点舍入或推理实现错误。

## E1 结果

配对条件沿用全部 E0 检查，未事后放宽。scene_00001 的 base 不合格，故该族两个配对被排除。仅 scene_00002 进入 E1。E1 使用已保存状态与专家特征，在 Colab CPU 上执行解码器。

| 变化 | 状态效应（固定 F_a） | 专家效应（固定 H_a） | 交互项 |
|---|---:|---:|---:|
| depth_swap | -0.00282977 | +2.24388036 | +0.00021167 |
| nuisance | -0.00409599 | +0.06648951 | +0.00246567 |

depth_swap 的四个关系分数为 r00=-1.17091549、r10=-1.17374526、r01=1.07296487、r11=1.07034677。在该配对中，交换专家特征使关系符号翻转，交换状态未使符号翻转。一个场景族无法提供跨场景可重复性证据，也无法证明小效应与零等价。E1 小效应对解码精度与执行设备的敏感性尚未专门验证。

## 当前结论与下一步

公开的原生解码器参数已恢复，完整深度读出已运行。当前样本支持继续调查“专家特征贡献较大、状态替换影响较小”的解码分支现象。语言答案是否使用这些状态尚未通过共享上游干预验证，E1 不提供该因果结论。

下一步先定位缓存模式导致的答案分歧，再扩大独立场景族并加入更丰富的空间关系与标记对照。当前不应根据本次 7/7 的深度结果或一个 E1 场景族启动修复训练。
